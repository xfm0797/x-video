# X-Video 2.0 设计规格（Windows 桌面单平台）

> 状态：草案 v1 · 面向 Windows 10 1809+ / Windows 11 x64
> 定位变更：从「跨平台 + 在线源聚合」转为「Windows 本地影音播放器」，追求格式覆盖、播放流畅度与观影体验。

---

## 1. 产品定位与边界

### 1.1 一句话定位

一个开箱即用、格式全吃、播放顺滑的 Windows 本地影音播放器，把「影视 / 短剧 / 音乐」三类内容做成三套贴合场景的浏览与播放形态。

### 1.2 与旧版的取舍

| 维度 | 旧版（v0.4.x） | 重做版（2.0） |
|---|---|---|
| 平台 | macOS / Linux / Windows | 仅 Windows（x64，后续可评估 arm64） |
| 内核 | 浏览器 `<video>` + hls.js，mpv 作为补丁 | mpv 作为唯一内核，全格式统一 |
| 内容来源 | TVBox / jx 网页解析 / Spider / 聚合搜索 / IPTV | 本地文件与目录（可选挂载网络位置） |
| 架构 | 内嵌 axum HTTP 服务 + WebView | Tauri IPC + 原生渲染面，去掉 HTTP 中间层 |
| 界面 | 单套点播式界面 | 影视 / 短剧 / 音乐 三套场景化形态 |

**移出 v1 范围**（保留扩展位，不实现）：在线点播源、IPTV 直播、网页解析、JS Spider 沙箱、聚合搜索、投屏、录制、云同步。

### 1.3 目标用户与核心场景

1. **影视**：本地下载的 MKV/MP4 剧集与电影，外挂字幕，看到一半关掉，下次接着看。
2. **短剧**：一个文件夹上百集竖屏短片，刷完一集自动下一集，可上下滑动切换。
3. **音乐**：整张专辑/整个文件夹连续播放，FLAC/APE 无损，歌词、封面、系统媒体控制。

## 2. 功能范围

### 2.1 必须做到（v1.0 验收线）

**A. 播放能力**

- 容器：MP4 / MKV / AVI / FLV / WMV / MOV / TS / M2TS / MPG / RMVB / WEBM / OGV / 3GP
- 视频编码：H.264 / H.265(HEVC) / AV1 / VP9 / VC-1 / MPEG-2 / MPEG-4 / RMVB(RealVideo)
- 音频编码：AAC / AC3 / EAC3 / DTS / TrueHD / FLAC / ALAC / MP3 / OPUS / Vorbis / WMA / PCM / APE / DSD(dsf,dff)
- 网络流：HTTP(S) 直链、HLS(m3u8)、RTSP、本地 m3u 播放列表
- 音频文件独立播放：MP3 / FLAC / APE / WAV / M4A / OGG / OPUS / WMA / DSD / CUE 分轨
- 硬件解码：D3D11VA 优先，失败自动回落软解；4K60 HDR 不丢帧
- 字幕：内嵌轨（PGS / ASS / SRT / VobSub）与外挂（同名 srt/ass/ssa/vtt/sub，自动模糊匹配），ASS 特效完整渲染

**B. 播放体验**

- 播放/暂停、进度拖拽（悬停缩略图预览）、±5s/±10s、逐帧、0.25–4.0x 变速不变调
- 音量/静音、音频轨切换、字幕轨切换、字幕延迟微调（±0.1s）
- 画面：比例切换（原始/16:9/4:3/填充/裁剪）、旋转、亮度/对比度/饱和度、HDR→SDR 映射
- 全屏/无边框窗口/画中画、多显示器、显示器热插拔恢复
- 截图（含/不含字幕）、书签打点、AB 循环

**C. 媒体库**

- 添加文件夹/整盘，递归扫描，增量更新（按 mtime+size 判断变更）
- 自动分类：影视 / 剧集 / 短剧 / 音乐 / 其他；按文件名规则归集剧集与专辑
- 元数据：时长、分辨率、编码、码率、音轨数、字幕数、HDR 标记
- 封面与缩略图：影视用同目录 poster/folder.jpg 或抽帧；音乐读内嵌封面；剧集抽首帧
- 浏览：网格 / 列表、搜索（文件名 + 标题）、筛选（类型/未看/最近添加/分辨率）、排序

**D. 连续播放与进度**

- 队列：来自剧集顺序、文件夹顺序、播放列表、搜索结果，可拖拽排序
- 自动下一集、播完行为可配（下一集/循环/停止）
- 断点续播：每 5s 落盘 + 暂停/切集/退出即时落盘，崩溃后可恢复
- 已看标记、观看进度条、跳过片头片尾（按剧集记忆时间点）
- 播放列表：手动创建、导入 m3u、导出

**E. Windows 集成**

- 文件关联（双击打开、右键「用 X-Video 播放」）、拖拽文件/文件夹到窗口
- 单实例（再次打开时把文件投递给已有窗口）
- 系统媒体控制（SMTC：锁屏/音量浮层显示封面与进度，支持上一集/下一集）
- 任务栏：进度条、缩略图工具栏按钮（播放/暂停/下一集）
- 全局快捷键（可自定义）、阻止休眠（播放中）、开机自启（可选）
- 记忆窗口位置与尺寸、Per-Monitor V2 DPI、深浅色跟随系统

### 2.2 明确不做（v1）

弹幕、在线字幕下载、视频编辑/转码、录屏、投屏 DLNA、皮肤系统、插件市场、移动端遥控。

### 2.3 后续版本（v1.x 预留）

在线字幕搜索、片段导出（GIF/MP4 剪辑）、音频可视化、DLNA 投屏、便携模式、arm64 构建。

## 3. 技术选型与关键决策

### 3.1 播放内核：libmpv（唯一内核）

| 方案 | 格式覆盖 | 硬解 | 体积 | 结论 |
|---|---|---|---|---|
| 浏览器 `<video>` | 差（无 MKV/RMVB/AV1 音频） | 受限 | 0 | 淘汰 |
| FFmpeg 自研管线 | 好 | 需自写 | 大 | 工作量过高 |
| VLC(libvlc) | 好 | 好 | 大 | GPL 传染、API 老旧 |
| **libmpv** | **最好** | **D3D11VA 成熟** | 中（~45MB） | **采用** |

- 分发 `libmpv-2.dll`（+ 必要字体/配置）随安装包，不依赖用户环境。
- 通过 `mpv_client_api` 的 **C API 动态加载**（`libloading`），而非编译期链接：升级内核只换 dll，CI 不需装 libmpv 开发包。
- 私有配置：`--config=no` 完全由应用下发参数，避免受用户全局 mpv 配置干扰。

### 3.2 画面上屏：三选一，先做 A，预留 B

HTML 无法覆盖原生视频窗口，这是 Tauri 类方案的核心矛盾。三条路：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 子窗口 + 外置控制条** | mpv `--wid` 嵌入子 HWND，控制条放在视频区外（底部条） | 稳定、零风险、已在本项目验证过 | 控制条无法浮在画面上，影院感打折 |
| **B. 透明 WebView 叠加** | mpv 窗口置于 WebView2 之下，WebView `transparent` 让视频区透出，HTML 控制条浮在最上 | 单窗口、UI 完全由 React 控制、可做沉浸式悬浮控制条 | 依赖 WebView2 透明合成，缩放/全屏可能闪烁，需 PoC |
| C. 独立播放窗口 + D2D 自绘 | 播放窗口用原生 Win32，控制条 Direct2D 画 | 最接近 PotPlayer 体验 | 两套 UI 体系，样式难统一 |

**决策**：M0 阶段对 B 做 2 天可行性验证（透明 WebView + mpv 子窗口 Z 序 + 拖拽缩放 + 全屏）。
- PoC 通过 → 采用 B，做出悬浮玻璃控制条、进度预览、弹幕式提示。
- PoC 失败 → 退回 A，控制条放在窗口底部固定区域，全屏时用 mpv 自带 OSC 的定制 lua 皮肤。

### 3.3 前端：React + TypeScript + Vite（保留）

- 不引入 UI 组件库，自建设计系统（CSS 变量 + 组件级样式），保证「一眼不同」的辨识度。
- 状态：轻量自研 store（Zustand 可选），播放状态由 Rust 事件驱动，单向数据流。
- 播放器 UI 与媒体库 UI 分离打包/懒加载，减少首屏体积。

### 3.4 数据层：SQLite（rusqlite + bundled）

- 单文件数据库放在 `%LOCALAPPDATA%\XVideo2\library.db`，WAL 模式。
- 全文搜索用 FTS5（文件名/标题/专辑）。
- 扫描与探测走批量事务；进度写入走独立小事务，避免与扫描锁冲突。

### 3.5 探测与缩略图

- **不额外打包 ffprobe**：用短生命周期 mpv 子进程（`--vo=null --ao=null --frames=0 --term-status-msg`）读 `track-list` / `duration` / `format`，并发限制 2–3，低优先级后台跑。
- 缩略图：`mpv --start=<t> --frames=1 --vo=image --o=<tmp.jpg>` 抽帧，生成 320px 宽 JPEG 存缓存目录，LRU 上限 500MB。
- 进度条悬停预览：预生成 10 张雪碧图（sprite）按需惰性生成，首帧不全量。

### 3.6 进程与窗口模型（实施修订）

> 落地时修订：**保留本地 HTTP 服务**作为前后端通道（原计划改为纯 Tauri IPC）。
> 原因：窗口加载 `http://127.0.0.1:<port>` 是历史上唯一稳定不白屏的路径，
> 且浏览器同源 fetch 让界面可以直接用 Chrome 截图调试。
> 安全对策：只监听回环地址 + 校验 Origin 头（`origin_guard` 中间件）。

**实施时的渲染决策**：M0 采用「控制条不覆盖画面」的分层布局——顶部标题条 +
视频区 + 底部控制条都是 WebView 的独立行，原生视频子窗口放在视频区内，
并用 `WS_EX_TRANSPARENT` 让鼠标事件穿透回 WebView（点击可切播放/暂停，
双击全屏仍有效）。悬浮玻璃控制条（方案 B）作为后续迭代。

### 3.6a 进程与窗口模型

```
┌─────────────────────────────────────────────┐
│ Tauri 主窗口（单窗口，Win32 + WebView2）      │
│  ┌───────────────────────────────────────┐  │
│  │ React UI（媒体库 / 播放器控制 / 设置）  │  │
│  └───────────────────────────────────────┘  │
│  ┌───────────────────────────────────────┐  │
│  │ 原生视频面（mpv --wid 子 HWND）        │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
        │ IPC（Tauri command / event）
┌───────▼─────────────────────────────────────┐
│ Rust：会话编排 · 媒体库 · 播放引擎 · 平台集成 │
└─────────────────────────────────────────────┘
```

- 单实例 + 单窗口，播放页是主窗口内的「影院模式」，不额外开窗（降低状态同步成本）。
- 去掉内嵌 axum 服务：改用 Tauri command + `asset` 协议读本地图片。**M0 需冒烟验证**，若再现白屏则保留最小静态服务作为兜底。

### 3.7 打包与更新

- 安装包：NSIS（主）+ MSI（企业），x64，内置 WebView2 引导（Win11 自带）。
- 自动更新：tauri-plugin-updater + GitHub Releases 的 `latest.json`。
- 签名：无证书阶段先出未签名包，文档注明 SmartScreen 提示。

## 4. 模块划分

### 4.1 分层

```
┌ UI 层 ────────────────────────────────────────────┐
│ Library  MediaPlayer  MusicMode  Settings  Shell  │
├ 应用编排层（xv-app）─────────────────────────────┤

├ 领域层 ───────────────────────────────────────────┤
│ xv-library（扫描/归集/索引）  xv-player（内核）    │
│ xv-media（探测/缩略图/字幕/标签）                 │
├ 平台层（xv-win）──────────────────────────────────┤
│ Surface  SMTC  Taskbar  Hotkey  SingleInstance    │
│ FileAssoc  Power  DPI                             │
├ 基础设施 ─────────────────────────────────────────┤
│ config  log  cache  db  updater                   │
└───────────────────────────────────────────────────┘
```

### 4.2 模块清单与关键特性

#### M1 `xv-media` — 媒体探测与素材

| 项 | 说明 |
|---|---|
| 职责 | 识别文件类型、读容器/轨道信息、抽帧生成缩略图、解析音频标签与歌词 |
| 关键特性 | ① 双层探测：快探（扩展名 + 文件头魔数，<5ms）与深探（mpv 轨道表，后台队列）<br>② 轨道清单结构化：视频/音频/字幕轨的语言、编码、声道、是否默认<br>③ 音频标签：ID3v2 / FLAC Vorbis / MP4 atoms / APE tag，取标题-艺术家-专辑-轨号-年份-内嵌封面<br>④ 歌词：同名 `.lrc`、内嵌 `LYRICS`/`USLT`，支持双语与偏移校正<br>⑤ 缩略图与雪碧图生成，带内容哈希去重 |
| 验收 | 1 万文件扫描（仅快探）< 30s；深探队列不阻塞 UI；缩略图命中缓存 < 10ms |

#### M2 `xv-library` — 媒体库与归集

| 项 | 说明 |
|---|---|
| 职责 | 目录扫描、增量更新、剧集/专辑归集、索引与查询、播放列表 |
| 关键特性 | ① 文件名清洗：剥离 `[1080p]` `WEB-DL` `H.265` `中字` `xx影视` 等噪声标签<br>② 集号识别：`S01E02`、`第12集`、`第十二集`、`EP12`、`- 012`、纯数字、`1-2` 多段<br>③ 剧集归集：同目录 + 清洗后同名 → 一部剧，按季/集排序；短剧按「剧名 + 集号」聚成一条卡片<br>④ 专辑归集：优先标签 album/albumartist，回退到文件夹名；CUE 分轨作为虚拟曲目<br>⑤ 竖屏判定：宽高比 < 0.75 → 标记为短剧形态<br>⑥ 增量：mtime+size 双键比对，删除项软删（保留进度 7 天）<br>⑦ 查询：分页 + 组合筛选 + FTS5 模糊搜索 |
| 验收 | 5000 集短剧归集准确率 > 95%；10 万条库首屏查询 < 80ms |

#### M3 `xv-player` — 播放引擎

| 项 | 说明 |
|---|---|
| 职责 | 封装 libmpv：生命周期、参数下发、命令、事件订阅、音视频设备策略 |
| 关键特性 | ① 动态加载 `libmpv-2.dll`，缺失时给出可操作提示（修复安装 / 指定路径）<br>② 硬解策略：`hwdec=d3d11va`，失败自动重试 `auto-safe`→`no`，并记录原因<br>③ 渲染：`vo=gpu-next`、`gpu-api=d3d11`、`d3d11-exclusive-fs`、自适应缩放算法<br>④ 音频：WASAPI 共享/独占切换，声道下混策略，`--gapless-audio=yes` 无缝连播<br>⑤ 事件流：`time-pos`/`duration`/`pause`/`volume`/`track-list`/`eof`/`file-loaded`/`video-out-params`，节流后推给前端（进度 4Hz）<br>⑥ seek：拖拽中用快速 seek（关键帧），松手用精确 seek（`hr-seek=yes`），互不阻塞<br>⑦ 播放快照：截图（含字幕与否）、当前轨道与滤镜状态可序列化 |
| 验收 | 本地 1080p 首帧 < 600ms、4K 首帧 < 1.2s；seek 响应 < 150ms；4K60 HEVC 硬解 CPU < 25%、零丢帧 |

#### M4 `xv-win` — Windows 平台集成

| 子模块 | 关键特性 |
|---|---|
| Surface | 创建/定位/裁剪视频子窗口，跟随窗口缩放与 DPI 变化，全屏切换，Z 序维护 |
| SMTC | 注册媒体会话，上报标题/艺术家/封面/进度/播放态，接收系统播放暂停切歌指令 |
| Taskbar | `ITaskbarList3` 进度与缩略图按钮（播放/暂停/下一集） |
| Hotkey | `RegisterHotKey` 全局热键（媒体键、老板键），可自定义并持久化 |
| SingleInstance | `CreateMutexW` + `WM_COPYDATA` 投递命令行参数 |
| FileAssoc | 安装器注册 ProgID 与「打开方式」，支持多格式勾选 |
| Power | 播放中 `SetThreadExecutionState` 阻止息屏/休眠 |
| DPI | Per-Monitor V2，跨显示器拖动后重建渲染面 |

#### M5 `xv-app` — 会话编排

| 项 | 说明 |
|---|---|
| 职责 | 把「一次播放」抽象为 Session：队列、当前项、进度、下一集、片头片尾、播放模式 |
| 关键特性 | ① 队列模型：来源 + 顺序/随机 + 单曲循环 + 列表循环<br>② 续播：位置每 5s 持久化，进入详情/开播时给出「从 12:34 继续」<br>③ 自动下一集：`eof` 后按队列推进，支持「播完回列表」<br>④ 跳过片头片尾：按剧集记忆时间点，首次手动标记，后续自动<br>⑤ 观看状态：未看/在看/已看/看到 xx%，驱动首页「继续观看」<br>⑥ 崩溃恢复：启动时读未完成会话，提示恢复 |
| 验收 | 连续播 20 集无内存增长；断电/强杀后进度丢失 ≤ 5s |

#### M6 UI — 三套场景化界面

**公共外壳**：侧栏（影视/短剧/音乐/本地文件/设置）+ 顶部全局搜索 + 底部常驻迷你播放条。

**影视（Movies）**
- 首页：继续观看横排 → 最近添加 → 分类（电影/剧集/动漫/纪录片）
- 详情页：背景大图 + 简介 + 季集选择 + 「播放/继续」
- 播放页：影院模式，暗场环境光，悬浮控制条（方案 B）或底部控制区（方案 A）

**短剧（Shorts）**
- 竖屏友好布局：卡片 9:16 封面，一屏 4–5 列
- 详情页：直接进播放，右侧集数网格（100 集也能快速定位）
- 播放页：竖屏居中 + 上下滑动切换下一集/上一集 + 单击暂停 + 双击点赞式收藏
- 自动连播、进度条极简（只显示集内进度与集号）

**音乐（Music）**
- 专辑墙 / 艺术家 / 歌曲列表三视图
- 播放页：大封面 + 滚动歌词（逐行高亮）+ 频谱或波形（v1.1）
- 无缝切歌、随机/循环、播放队列抽屉
- 迷你模式：300×300 悬浮小窗，仅封面 + 控制
- 系统媒体控制联动（SMTC 封面与歌词标题）

**设计语言**
- 深色为主（视频场景刚需），支持浅色；主色一个强调色，不做花哨渐变堆叠
- 动效克制：转场 180–240ms，卡片悬停位移 ≤ 4px，列表虚拟滚动
- 关键辨识点：播放页背景取当前帧做高斯模糊环境光（随画面变化缓动）
